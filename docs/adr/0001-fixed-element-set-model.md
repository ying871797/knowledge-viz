# 固定元素集 + 纯插值的场景模型

状态：accepted

场景渲染采用固定元素集：全部单体杆、着丝点、标注在挂载时一次创建，此后任何阶段切换只做位置/角度/透明度插值，禁止 DOM 增删，禁止按阶段改变元素结构的分支。

背景：减数分裂动画的早期形态曾按阶段条件渲染元素（出现/消失），导致布局特判分支滋生、阶段过渡跳变、可读性约束无法测试。2026-08 动画重构为固定 8 单体杆 + 8 着丝点 + 8 标注的纯插值模型后，layout 成为纯函数（逐阶段槽位表），间距等不变式全部落为 `scene.test.ts` 断言。

## Considered Options

- **逐阶段条件渲染**（否决）：实现上更直觉，但元素增删本身就是视觉噪音，破坏"运动即语义"；且每阶段结构不同使不变式矩阵不可测。
- **引入补间动画库/前端框架**（否决）：需求只是关键帧几何插值，原生 rAF 足够；引入依赖违背最小化原则。

## Consequences

- 新阶段的成本 = 写一张槽位表（声明数据），不是写渲染逻辑。
- 「隐藏某元素」必须表达为透明度/位移归零，而不是移除节点。
- 按 stage id 的 switch/case 槽位表是本模型的合法数据形态，勿误当特判分支"修复"。
