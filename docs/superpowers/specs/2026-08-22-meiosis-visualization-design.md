# 设计文档：高中生物知识点可视化工作流（试点：减数分裂）

日期：2026-08-22
状态：已批准（方案文档见 `.proposals/2026-08-22-meiosis-visualization.html`）

## 1. 目标与背景

高中生物核心概念（减数分裂、DNA 复制、光合与呼吸等）过程抽象，课本静态插图难以表达动态变化。本项目建立一套可持续扩展的可视化课程工作流，把难点知识点转化为在线网页上的分步动画 + 可交互演示。

- 使用对象：学生自学（浏览器打开即可，手机可访问）
- 交付形式：在线静态网页（GitHub Pages 托管）
- 第一期规模：仅试点「减数分裂」一个知识点，验证模板后再批量扩展
- 内容参考来源：《高中生物知识点.docx》（人教版必修一/二问答式要点），生物学表述严格对照教材

## 2. 技术选型

**Vite + TypeScript + SVG 动画引擎**，纯静态构建产物。

| 备选 | 结论 | 理由 |
|---|---|---|
| A. Vite + TS + SVG | ✅ 采用 | 包体小、矢量精度高、元素可绑定交互；数据驱动模板便于批量扩展 |
| B. Vite + React + Canvas(PixiJS) | ❌ | 依赖重，二维示意场景收益低 |
| C. reveal.js 幻灯片定制 | ❌ | 拖拽与自由动画受限 |

SVG 能力边界：碱基配对、染色体行为等二维矢量动画完全胜任；3D 结构（需 Three.js）和大规模粒子特效不在本期范围。

部署：GitHub Actions 自动 `npm run build` 并发布 `dist/` 到 GitHub Pages；备选 Vercel / Netlify（产物相同）。构建时配置正确的 base 子路径。

## 3. 目录结构

```
knowledge-viz/
├── index.html              # 首页：知识点目录导航
├── src/
│   ├── core/               # 通用引擎（所有知识点共用）
│   │   ├── player.ts       # 分步播放器状态机
│   │   ├── scene.ts        # 场景组件接口定义
│   │   ├── numberChart.ts  # 通用 SVG 数目曲线图组件
│   │   └── notes.ts        # 阶段讲解文案面板
│   ├── courses/
│   │   └── meiosis/
│   │       ├── data.ts     # 阶段数据、讲解文案、数目数据
│   │       └── scene.ts    # 减数分裂 SVG 场景
│   └── main.ts             # 入口路由
└── docs/superpowers/specs/
```

核心原则：

1. **数据与渲染分离**——`data.ts` 描述阶段/文案/数目，`scene.ts` 负责画面；新增知识点 = 新建课程模块，零引擎改动。
2. **状态机驱动动画**——每阶段为离散状态，SVG 属性随状态插值过渡；前进/后退即状态切换；三条数目曲线与主场景共享同一状态机自动联动。

## 4. 数据结构

```typescript
interface Stage {
  id: string;               // 如 "prophase-I"
  title: string;            // "减Ⅰ前期"
  narration: string[];      // 讲解要点 + 易错点
  sceneState: object;       // 场景渲染参数，如 { homologousPairs: "paired", crossingOver: true }
  numbers: {
    chromosome: number;
    dna: number;
    chromatid: number;
    dnaPerChromosome: number;
  };
}

interface Course {
  meta: { id: string; title: string; chapter: string; difficulty: number };
  stages: Stage[];
}
```

注：自测题功能按用户要求从第一期移除；未来扩展题库时再增加字段。曲线图完全由 `numbers` 字段自动绘制，新增/调整阶段无需改动图表代码。

## 5. 减数分裂场景设计

### 5.1 布局

两栏：左侧阶段讲解面板（当前要点 + 易错提示），右侧 SVG 主场景；下方为数目变化动态图。移动端上下堆叠。

### 5.2 十个阶段

| # | 阶段 | 关键动画 / 教学点 |
|---|---|---|
| 1 | 精原细胞（间期前） | 基态 2n=4，两对同源染色体以不同长度+颜色区分 |
| 2 | 间期 | 染色体复制渐显（姐妹染色单体出现） |
| 3 | 减Ⅰ前期 | 联会 → 四分体 → 交叉互换片段高亮闪烁 |
| 4 | 减Ⅰ中期 | 同源染色体成对排列于赤道板两侧 |
| 5 | 减Ⅰ后期 | 同源分离；「自由组合」开关切换两种非同源组合对比 |
| 6 | 减Ⅰ末期 | 形成两个次级精母细胞 |
| 7 | 减Ⅱ中期 | 染色体排列于赤道板 |
| 8 | 减Ⅱ后期 | 着丝粒分裂，姐妹染色单体分开 |
| 9 | 减Ⅱ末期 | 四个精细胞 |
| 10 | 变形 | 精子 |

### 5.3 交互

- 播放控制：连续播放 / 暂停 / 单步前进后退 / 进度条任意跳转；步间补间约 1.5s
- 点击染色体 → 气泡说明：染色体类型、染色单体数、有无同源染色体
- 开关①：非同源自由组合对比（阶段 5）；开关②：基因标注 A/a、B/b（可观察交叉互换后的重组基因型）
- 易错警示：如减Ⅱ时期「无同源染色体」判断点

### 5.4 数目变化动态图（双向联动）

两条并列曲线图，共用同一横轴（10 个阶段）：

1. **细胞内总数曲线**：DNA 数、染色体数（实线）、染色单体数（虚线）
2. **每条染色体 DNA 数曲线**：1→2→1 平台；标注两个突变点（间期复制 1→2、减Ⅱ后期着丝粒分裂 2→1）

联动规则：

- 进入某阶段时发光标记点沿曲线滑动至对应位置，后退则回滑；拖进度条时标记吸附跳转；点击曲线数据点 → 主场景跳至该阶段
- 关键拐点自动弹出标注气泡：减Ⅰ末期「染色体 4→2（同源分离的实质）」、减Ⅱ后期「染色体 2→4（着丝粒分裂致暂时加倍）」
- 可勾选隐藏单条曲线（如先只看染色体数让学生预测 DNA 变化）
- 「据图判断练习模式」：隐藏全部曲线与阶段标签，学生看画面判断时期后揭晓答案（高考「据图判断时期」题型训练）

## 6. 错误处理与测试

- **数据校验 fail-fast**：课程数据加载后校验（阶段数与曲线数据点一致、数值非负、sceneState 字段完整），不合格在控制台报错并显示占位提示，不静默渲染错误画面
- **日志策略**：记录课程加载入参、阶段切换决策与异常；循环体内不记录
- **测试范围**：
  - core 引擎单元测试：播放器状态机边界（首步后退、末步前进、任意跳转）、数据校验逻辑
  - SVG 场景视觉内容不做快照测试，采用浏览器手动验收 + 用户审阅

## 9. 风险与回滚

| 风险 | 应对 |
|---|---|
| 数据结构与曲线不一致导致渲染错误 | 结构校验 fail-fast + 占位提示 |
| 低端手机动画卡顿 | 元素数量控制在几十级；必要时缩短补间时长 |
| GitHub Pages 不稳定 | 产物为通用静态文件，可随时切换 Vercel/Netlify |
| 生物学内容准确性 | 严格对照教材；交叉互换、自由组合细节实现后经用户审阅再发布 |

回滚：全新独立目录，无既有代码改动，无破坏性影响；Git 管理保证任何阶段可回退。
